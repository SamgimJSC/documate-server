# 연간 소비 패턴 — 참고 위젯 실현 가능성 검토

"AI Premium Report" 참고 이미지(9개 위젯 + 이번달 AI 요약)를 기준으로,
실제 `receipts` / `spend_categories` / `monthly_reports` 스키마를 다시 확인해서
어떤 위젯을 지금 만들 수 있는지 정리한 문서입니다.

## 스키마 재확인

- `receipts`: `spend_category_id`, `store_name`, `total_amount`, `purchase_date`(**date, 시간 없음**), `payment_item`, `memo`, `is_confirmed` 등.
- `spend_categories`: `name`, `icon` — 시스템 공용 카테고리 테이블(사용자별 커스텀 아님). 현재 테스트 계정 기준 실사용 카테고리: 교통 · 식비 · 쇼핑 · 카페.
- `monthly_reports`(`ai_analysis`, `predicted_spend`, `category_breakdown` 등): 컬럼은 있으나 이걸 채우거나 읽는 서비스/컨트롤러가 전혀 없음(죽은 스캐폴드). 즉 AI 문구는 전부 프론트 템플릿으로 생성해야 함(이미 월간 탭에서 하던 방식).
- `purchase_date`가 **date 타입**이라 "몇 시에 소비했는지"는 절대 알 수 없음. day-of-week(요일)은 date만으로 계산 가능하므로 문제 없음.

## 이번에 추가하는 것 (구현 순서)

1. **백엔드**: `GET /reports/weekday-summary?year=` — `top-stores`와 동일한 패턴으로 `EXTRACT(DOW FROM purchase_date)` GROUP BY, 요일별 합계/건수 반환.
2. **월간 탭**: "이번 달 소비 랭킹" — 이미 계산 중인 `sortedCategoryData` 상위 3개를 메달(🥇🥈🥉 아이콘 대신 순위 배지)로 표시.
3. **연간 탭**에 위젯 4개 추가:
   - **소비 성향 분석(레이더)**: 연간 카테고리 비중을 축으로 매핑(예: 비중이 높을수록 "관리 필요" 낮은 점수, 축은 실제 카테고리명 사용).
   - **AI 소비 코칭**: 주말/평일 합계 비교 텍스트 + 가정 절감률 기반 예상 절약액.
   - **절약 가능 금액 시뮬레이션**: 연간 지출 상위 카테고리 최대 3개에 가정 절감률(15%/20%/10%) 적용, 총 절약 가능액 계산.
   - **소비 위험도**: 월별 지출 변동계수(표준편차/평균) + 최대 카테고리 쏠림 비율로 0~100점 산출, 반원 게이지로 표시.
4. **캘린더 위젯 크기 축소**: 카드 폭을 꽉 채우던 문제 수정 — `max-width: 300px`, 셀 간격/폰트 축소.

## 명시적으로 안 하는 것

- 시간대별 분석(6): 스키마 변경 필요, 이번 스코프 아님.
- 다음 달 예측의 "증가 사유" 추정(8): 반복 결제 탐지 등 설계가 더 필요해 다음 단계로 미룸. 기존 단순 예측치만 유지.
