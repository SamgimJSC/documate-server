DocuMate 프로젝트 기획서 (최종)
종이 서류를 찍으면 AI가 알아서 정리하고, 소비패턴까지 분석해주는 지능형 문서 관리 플랫폼
________________


1. 서비스 개요
프로젝트명: DocuMate
한줄 소개: 종이 서류를 찍으면 AI가 알아서 정리하고 소비패턴까지 분석해주는 플랫폼 
타겟: 종이 서류와 영수증을 자주 보관해야 하는 개인 사용자 
기획 배경: 일본 아날로그 문서 문화(종이 계약서, 보증서, 처방전, 영수증 등) → 분실/훼손/기한 놓침 문제 해결 + 일본 DX 국가 정책 흐름과 맞닿은 서비스
________________


2. 플랜 구조
Free 플랜 (기본)
* 문서 업로드 / AI 자동 분류
* 만료일 알림(어플/메일)
* 문서 검색 / 보관
* 간편 가계부(영수증 기반 월별 지출 및 소비 분야 확인)
Pro 플랜 (유료 — 카카오페이 결제)
* Free 플랜 전체 포함
* 월별 소비 리포트 자동 생성
* AI 소비패턴 분석
* 연간 지출 타임라인
* 이미지 마스킹 기능
* PDF 병합 다운로드
________________


3. 핵심 기능
기능 1 — 스마트 업로드 (영은)
* PDF / 이미지 드래그 앤 드롭 일괄 업로드
* 민감정보(주민번호, 서명 등) 마스킹 UI (Pro)
기능 2 — AI 문서 분석 (OCR + LLM) (예진)
* GPT-4o Vision API로 문서 종류 자동 분류
* 만료일 / 금액 / 갱신일 등 핵심 데이터 JSON 추출
* 영수증 특화 파싱 (날짜 / 가게명 / 카테고리 / 금액) (Pro)
기능 3 — 스마트 알림 스케줄러 (예진)
* 서류별 갱신 및 만기일 맞춤 알림 설정
* 설정된 기간 변경 기능
* 이메일 알림 / 실시간 푸시 알림 (알림 방식은 유저가 직접 선택함)
* 소비패턴 기반으로 카드 추천(Pro) 
* 반복 소비 학습을 통한 상기 알림(APP)
기능 4 — 디지털 캐비닛 (영은)
* 키워드 검색으로 문서 즉시 조회(Elasticsearch)
* 파일별 태그 분류 생성 및 조회
* 문서 PDF 병합 다운로드 (Pro)
기능 5 — 통계 대시보드 (마지막)
* 스토리지 사용 현황(플랜에 따라 다르게)
* 다가오는 일정 표시
* 문서 스캔 및 업로드란
* 최근 업로드한 문서(디폴트), 즐겨찾기 (탭변환)
* 월별 소비 리포트 + AI 소비패턴 분석 (Pro)
기능 6 — 결제 시스템 (선형)
* 카카오페이 API 연동
* 결제 성공 시 webhook → DB 플랜 업그레이드 자동화
