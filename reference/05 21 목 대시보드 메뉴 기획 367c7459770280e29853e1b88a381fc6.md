## 1. 영수증 파일 업로드 방식

### 논의 사항

영수증 파일을 사용자가 전부 업로드하게 할 것인지, 필요한 영수증만 선택해서 업로드하게 할 것인지에 대해 논의함.

### 정리 방향

용량 문제를 크게 고려하지 않는다면, 사용자가 필요한 파일을 자유롭게 업로드할 수 있도록 한다.

다만 별도의 **문서 업로드 전용 페이지**를 사이드 메뉴에 만들지는 않는다.

### 최종 방향

어느 페이지에서든 `+ 버튼`을 누르면 드래그 앤 드롭 방식으로 파일을 업로드할 수 있도록 구현한다.

업로드된 파일은 파일 종류에 따라 자동 분기한다.

- 영수증 파일인 경우
→ OCR 처리를 거쳐 **영수증 관리 페이지**로 이동
- 일반 문서 파일인 경우
→ **디지털 캐비닛**에 저장

---

## 2. 주요 메뉴 구조

사이드 메뉴는 다음과 같이 구성한다.

- 대시보드
- 디지털 캐비닛
- 영수증 관리
- 소비 리포트(Pro)

### 소비 리포트(Pro) 처리 방식

소비 리포트 메뉴는 사이드 메뉴에 그대로 유지한다.

- Pro 사용자가 아닌 경우
→ 프로모션 / 요금제 업그레이드 페이지로 이동
- Pro 사용자인 경우
→ 소비 리포트 페이지로 이동

---

## 3. 디지털 캐비닛 및 문서 상세 페이지

디지털 캐비닛에서 특정 문서를 클릭하면 **문서 상세 페이지**로 이동한다.

문서 상세 페이지에서는 문서별 알림 설정을 관리할 수 있도록 한다.

### 알림 설정 방식

- 알림 설정 토글은 중복 설정이 불가능하도록 한다.
- 문서별로 사용자가 직접 알림 날짜를 설정할 수 있도록 `+ 버튼`을 추가한다.
- 문서 종류에 따라 기본 알림 기간은 하드코딩으로 세팅한다.
- 문서 등록 시 자동으로 모달을 띄워 기본 알림 설정 기간을 안내한다.

### 알림 설명 기능

알림에는 단순 날짜뿐만 아니라 사용자가 알림 사유를 이해할 수 있도록 설명을 추가한다.

예시:

- 세금계산서를 거래처에 발행했다.
- 계약 만료일 전에 확인이 필요하다.
- 보험 갱신일이 다가온다.

사용자가 직접 부연 설명을 입력할 수 있는 입력란을 제공한다.

## 4. 대시보드 구성

대시보드 하단에는 기존과 동일하게 광고 영역 또는 Pro 모드 유도 영역을 유지한다.

해당 영역을 통해 사용자가 Pro 기능을 인지하고 업그레이드할 수 있도록 유도한다.

## 5. 마이페이지 및 설정 구조

### 마이페이지 진입 방식

마이페이지는 사이드 메뉴에 두기보다 다음 방식 중 하나로 구성한다.

- 상단 메뉴에 따로 배치
- 프로필 사진 클릭 시 마이페이지로 이동

### 마이페이지 구성

마이페이지에는 다음 항목을 포함한다.

- 프로필
- 요금제 업그레이드
- 설정
- 로그아웃

### 요금제 업그레이드

요금제 업그레이드 메뉴 클릭 시 프로모션 페이지로 이동한다.

### 설정 위치

설정은 기본적으로 마이페이지 내부에 위치시킨다.

다만 설정을 자주 변경해야 하는 기능이 많아질 경우, 별도 설정 아이콘으로 분리하는 방안도 고려한다.

---

## 6. 알림 및 푸시 기능

### 알림 채널

알림은 다음 방식으로 제공한다.

- 이메일 알림
- 앱 푸시
- 웹 푸시

사용자는 토글을 통해 원하는 알림 방식을 선택할 수 있도록 한다.

### 기능적 구분

앱 푸시와 웹 푸시는 기능적으로 구분하여 처리한다.

- 앱 푸시
→ 모바일 앱 사용자 대상
- 웹 푸시
→ 웹 서비스 사용자 대상

### 알림 데이터 처리

알림 정보는 데이터베이스에 저장한다.

저장된 알림 데이터를 기반으로 알림 사유가 발생하면 DB에서 데이터를 가져와 웹 푸시 또는 앱 푸시를 발송한다.

알림 자체는 휘발성으로 처리되지만, 알림 발송 기준이 되는 데이터는 DB에 저장하여 관리한다.

---

## 7. 알림 설정 흐름

사용자는 문서별로 알림 방식을 선택할 수 있다.

### 예시 흐름

1. 사용자가 문서를 업로드한다.
2. 시스템이 문서 종류를 판별한다.
3. 문서 종류에 따라 기본 알림 기간을 자동 설정한다.
4. 사용자에게 모달로 알림 설정 기간을 안내한다.
5. 사용자는 필요 시 알림 날짜를 직접 추가하거나 수정한다.
6. 사용자는 이메일 / 앱 푸시 / 웹 푸시 중 원하는 알림 방식을 토글로 선택한다.
7. 설정된 알림 정보는 DB에 저장된다.
8. 알림 조건이 충족되면 DB 데이터를 기반으로 알림을 발송한다.
